# Мини-футбол 1×1 — 3D

3D мини-футбол на двоих за одной клавиатурой. Сцена и игровая логика сделаны в [Spline](https://spline.design), сайт — Next.js.

| | Красный | Синий |
|---|---|---|
| Движение | `W` `A` `S` `D` | `↑` `←` `↓` `→` |
| Удар | `F` | `.` |
| Прыжок | `G` | `/` |

`Esc` — пауза, `R` — новый матч. Играем до 5 голов.

## Как устроено

Игра (физика, счёт, меню, звук) живёт внутри сцены Spline как HTML-контент и едет вместе с файлом `scene.splinecode`. Сайт подключает сцену через `@splinetool/react-spline` в режиме `htmlContentMode="inline"` — скрипты игры работают прямо на странице.

Ссылка на сцену задаётся в `.env`:

```
NEXT_PUBLIC_SPLINE_SCENE=https://prod.spline.design/<id>/scene.splinecode
```

Чтобы обновить сцену: правите в Spline → Export → Code → **Update**. Ссылка не меняется, сайт подхватит новую версию сам.

## Запуск

```bash
npm install
npm run dev
```
